# BC2 – MERN Project Starter

This repository is a minimal MERN starter skeleton.

## Purpose

This repository is intentionally kept raw. It provides a basic project workspace so you can clone the project and begin development without starting from an entirely empty folder.

The **Project Requirement Document** is the source of truth for what needs to be built. The structure in this repository is only a starting point.

## Stack

- MongoDB
- Express.js
- React.js
- Node.js

## Important

This is **not a fixed architecture**. Add, remove, rename, or reorganize files and folders as required by your implementation.

No business logic, database schema, API implementation, authentication, CRUD operations, or completed UI is provided intentionally.

Some empty directories may contain a `.gitkeep` file so Git can track them. **Remove the `.gitkeep` file when you start adding your actual files to that directory.**

## Getting started

1. Clone the repository.
2. Install the frontend and backend dependencies.
3. Create your environment variables using the provided examples.
4. Read the Project Requirement Document carefully.
5. Decide your application structure and implementation approach.
6. Build the project step by step and test your work as you go.
